# Hola, soy Fran Bravo

Soy **desarrollador web full stack orientado al backend**. Trabajo principalmente con **Python, Django, SQL, PostgreSQL, JavaScript y React** para construir aplicaciones web útiles, mantenibles y conectadas con necesidades reales.

Me interesa especialmente convertir un problema de negocio en una solución completa: comprender los flujos, modelar los datos, desarrollar la lógica, cuidar los permisos, probar el comportamiento, desplegar la aplicación y documentarla con claridad.

Actualmente estoy finalizando el **Máster en Desarrollo Web Full Stack de Conquer Blocks**. Mi Proyecto Fin de Máster, AgendaSalon, está desarrollado, publicado y pendiente de evaluación.

## Proyecto principal

### [AgendaSalon](https://github.com/fjbravo75/agendasalon)

Aplicación web para gestionar citas, clientes, profesionales y reservas online en peluquerías, barberías y pequeños salones de belleza.

AgendaSalon reúne la agenda interna del negocio, la reserva pública, la gestión de clientes y la administración de la plataforma. Está construido principalmente con **Django y PostgreSQL**, mientras que **React** se utiliza en las interfaces que requieren una interacción más dinámica.

La disponibilidad, los permisos y el aislamiento de los datos se resuelven en el servidor. El proyecto incluye pruebas automatizadas, integración continua sobre SQLite y PostgreSQL y un despliegue público con Gunicorn, Nginx y HTTPS.

## Cómo trabajo

Antes de desarrollar, procuro entender el problema, los usuarios, los datos y las reglas que debe respetar la aplicación. Valoro el código comprensible, las validaciones, la seguridad, las pruebas y una documentación que permita ejecutar y revisar el proyecto sin depender de mi entorno.

También utilizo herramientas de inteligencia artificial y agentes de desarrollo como apoyo para analizar requisitos, explorar alternativas, preparar primeras versiones, revisar código, ejecutar pruebas y mantener la documentación.

No considero terminada una salida generada hasta haberla entendido, revisado y comprobado. Las decisiones de producto y arquitectura, la integración de los cambios y la validación final son responsabilidad mía.
